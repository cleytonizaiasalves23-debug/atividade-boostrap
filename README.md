# 🍖 Canto do Churrasqueiro

Uma aplicação web desenvolvida para ajudar na organização de churrascos e eventos, permitindo calcular de forma rápida e prática as quantidades necessárias de carnes, bebidas e acompanhamentos.

---

## 📌 Sobre o Projeto

O **Canto do Churrasqueiro** é uma aplicação web desenvolvida como projeto front-end.

A plataforma reúne ferramentas para auxiliar no planejamento de eventos, oferecendo uma calculadora de churrasco e uma página de contato.

---

## 🎯 Objetivo

O objetivo do projeto é facilitar o planejamento de um churrasco, permitindo que o usuário informe os dados do evento e obtenha uma estimativa da quantidade necessária de:

- 🥩 Carnes
- 🥤 Bebidas
- 🥗 Acompanhamentos

A aplicação busca apresentar os resultados de maneira simples, rápida e organizada.

---

## 🚀 Funcionalidades

### 🏠 Página Inicial

**`index.html`**

Página principal do projeto, responsável por apresentar o **Canto do Churrasqueiro** e suas principais funcionalidades.

---

### 🧮 Calculadora de Churrasco

**`Calculadora.html`**

Permite realizar uma estimativa dos produtos necessários para um churrasco.

A calculadora utiliza os dados informados pelo usuário para realizar os cálculos através do JavaScript.

Entre os cálculos estão:

- Quantidade de carne;
- Quantidade de bebidas;
- Quantidade de acompanhamentos.

---

### 📩 Página de Contato

**`contato.html`**

Página destinada ao contato com o usuário, disponibilizando um formulário para dúvidas, sugestões e feedback.

---

### 📱 Design Responsivo

O projeto foi desenvolvido para funcionar em diferentes dispositivos:

- 📱 Celulares;
- 📲 Tablets;
- 💻 Computadores;
- 🖥️ Notebooks.

O **Bootstrap 5** foi utilizado para auxiliar na criação de um layout responsivo.

---

## 🛠️ Tecnologias Utilizadas

### HTML5

Utilizado para criar a estrutura das páginas do projeto.

### CSS3

Utilizado para personalizar a aparência da aplicação, incluindo cores, fontes, espaçamentos e organização dos elementos.

### Bootstrap 5

Utilizado para criação do layout responsivo e componentes da interface.

### JavaScript

Utilizado para implementar a lógica da aplicação e realizar os cálculos da calculadora de churrasco.

### Bootstrap Icons

Utilizado para adicionar ícones e melhorar a apresentação visual da aplicação.

---

### 📱 Responsividade

O projeto utiliza recursos do Bootstrap 5 para adaptar o conteúdo a diferentes tamanhos de tela.
Dessa forma, os elementos da página podem se reorganizar para proporcionar uma melhor experiência em celulares, tablets e computadores
